SIM action icons

Options for each SIM card action the staff app has, built on the SIM symbol it already uses (lucide's CardSim, the SIM Cards tile) with a badge in the bottom-right corner, lucide's way of saying "this thing, plus an act". Every icon is on lucide's 24 grid with a 2px stroke and round ends, so it sits beside Pencil, Printer and KeyRound in the action bar. Each is shown at 64, 24 and 16px, in a button with words, as an icon-only tool and as a ⋯ item.

Using them

  • Words. The app says Give, not Assign, and Blocked, not Deactivated (glossary §12): Assign SIM is Give SIM's icon, Deactivate is Block's. Replace SIM is not an action today (it is a Return, then a Give); its icon waits for it.
  • Where SIM badges go. On a SIM card's own action bar, Change Status ▾ and ⋯ the badge carries the act. Equipment keeps plain icons for Give Asset and Return (an arrow without the card), so a SIM icon never stands for a laptop.
  • Generic stays generic. Edit (Pencil), Print Form (Printer), Upload Signed Form (Upload), Copy numbers (Copy) and Export keep the vocabulary's icons: the screen already says it is a SIM.
  • Status colour. In Change Status ▾ the three status icons may take the status colours (Active green, Blocked red, Not Activated amber), as the badges do; in the action bar they stay the text colour.
  • Vocabulary. Each adopted icon becomes one entry in actionIcons (@ppe/ui/lib/record-actions.ts), made with lucide's createLucideIcon from the nodes below, so it is a LucideIcon like the rest.
