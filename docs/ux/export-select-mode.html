Improvement after WARE-43 and WARE-44 · proposal and interactive mockup · 2026-11-20

Checkboxes only while exporting

Today every list has a checkbox column that is always on, so a row has two jobs (open it, or tick it), and phones can't tick at all. The proposal: a list shows no checkboxes until you start an action that needs them. Export (and, on SIM Cards, Change Status) puts the list into a select mode: the checkboxes appear, a bar names the action and counts the rows, and leaving the mode puts the list back as it was.

Recommendation: start with the action, then pick the rows. The checkboxes only appear when an action needs them, the bar always says what the selection is for, a row tap in the mode ticks it instead of opening it, and phones can finally pick rows. On a list without selection, Export works as it does now.

Try it

Click Export, tick rows (click anywhere on a row), then Export n… or Export all…. Esc or Cancel leaves the mode. On SIM Cards, Change Status uses the same mode. Switch to Phone to see the bottom bar.

How it behaves

  1. Browsing (the default): no checkbox column. A row opens its record, as before WARE-43. The header keeps Export; on a phone it's in ⋯.
  2. Export enters select mode, with nothing ticked:
    • The checkbox column appears, with the header checkbox for all shown.
    • Above the list, the bar reads "Export Employees · Tick the rows to export, or export them all" with Export n… (primary, off at 0), Export all n… and Cancel.
    • On a phone the bar sits at the bottom, above the tab bar, with 44 px buttons in thumb reach.
    • Focus moves to the bar and a screen reader hears its words.
  3. In the mode:
    • Tapping or clicking a row ticks it, and the record doesn't open. The name stays a link: ⌘/Ctrl-click opens it in a new tab.
    • The tabs, search and sort still work, and the selection is kept for the rows still shown.
    • The row actions (Edit Sizes, ⋯) are hidden, so nothing else competes with picking.
    • Space ticks the focused row and Esc leaves the mode.
  4. Export n… or Export all… opens the Export sheet. The rows are already decided, so the sheet shows them as a summary with a Change link back to the list, then the columns and the format. The Rows radio goes away.
  5. After the file downloads, the mode ends and the selection clears. Cancel or Esc ends it at any time.
  6. Lists loaded page by page (Orders, SIM Cards, Equipment):
    • Export all… reads "Export all 70 matching…" and exports every page.
    • Ticking works on the page shown and is kept when you move to another page, so you can tick across pages.
  7. SIM Cards' Change Status becomes a header action (for sim_cards.manage) that enters the same mode. Its bar reads "Change Status · n selected" with a status menu instead of Export. One list is only ever in one mode at a time.

What changes in the code

  • @ppe/ui:
    • useSelection gains mode (null or the action's key) with start(action) and end(); ending clears the selection.
    • SelectionBar becomes SelectModeBar: the action's title and hint, the count, the action's buttons, Cancel; sticky on top from md and a bottom bar below.
    • RowCheckbox and SelectAllCheckbox render only in the mode.
    • A useSelectModeRow(id) helper turns a row's click into a toggle while the mode is on (links still open on ⌘/Ctrl-click).
  • ExportSheet: rows becomes fixed ("3 employees", "all 70 matching"), shown as a summary with Change (back to the mode). onExported ends the mode.
  • Every list from WARE-43/44:
    • The header's Export starts the mode instead of opening the sheet.
    • Lists without a table (Item Sets, Replacements, Items given) keep Export opening the sheet straight away.
    • The stacked phone list shows checkboxes in the mode too, so the mode bar replaces the phone's "exports all shown" rule.
  • SIM Cards: Change Status in the header (manage only) starts its own mode; the bulk status menu moves into that bar.
  • Tests:
    • Unit tests for the mode in use-selection.
    • e2e:
      • the Employees, Orders/Users and SIM Cards steps go through the mode;
      • the steps that adjusted for the checkbox cell (the Catalogue sort, the Roles rows) go back to their first forms.
    • "No screen scrolls sideways" covers a list in the mode at phone width.

Done when

  • No list shows checkboxes while browsing. Export and Change Status start the mode; Cancel, Esc and a finished export end it.
  • In the mode a row tap ticks and never opens the record. The count, Export n… and Export all… are right after filtering and paging.
  • Phones can tick rows, with the bar at the bottom and 44 px targets.
  • The words are in EN, LT and RU: "Export Employees", "Tick the rows to export, or export them all", "Export 3…", "Export all 142…", "Cancel". "Select mode" is added to the glossary and ui-language.md.
  • Screenshots on desktop and phone, and e2e green.
